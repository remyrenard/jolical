# Vos polices

Déposez ici vos fichiers de polices (`.woff2`, `.woff`, `.ttf` ou `.otf`) : ils apparaissent dans les listes de polices de
**Paramètres > Apparence**, en plus des polices libres fournies avec Jolical (dossier `fonts/`).

Ce dossier est monté en lecture seule dans le conteneur (`/fonts`). Son contenu n'est pas suivi par Git :
vérifiez la licence d'une police avant de la partager.
