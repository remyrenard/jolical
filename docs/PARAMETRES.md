# Paramètres

## Paramètres généraux

Langue (lang) : liste des fichiers texts_XX.json disponibles ; affichée seulement s'il y a plusieurs langues  
Titre de la page (title)  
Vue préférée (startView)  
Calendrier par défaut (defCal)  
Liste de tâches par défaut (taskCal)  
Calendrier des anniversaires (bdayCal)  
Afficher les anniversaires dans les vues : Mois, Année (bdayMonth, bdayYear)  
Durée par défaut des évènements (min) (evDur)  
Heure des rappels par défaut (remTime)  
Début de l’après-midi (pmStart)  
Début de la soirée (evStart)  
Filtrer les tâches commençant par (taskFilter)  
Afficher les tags dans l’aperçu (showTags)  
Autoriser les iframes (frameOn, frameSrc)  

## Liens externes

Nom de la catégorie (toolsName)  
Afficher le lien vers l'Agenda Nextcloud (toolsCal)  
Afficher le lien vers les Decks Nextcloud (toolsDeck)  
Afficher le lien vers les Tâches Nextcloud (toolsTasks)  
Liens externes : intitulé + URL, 10 au plus (links)  

## Apparence

Thème (theme) : Par défaut, Clair, Sombre, Vert Clair, Vert Foncé (fournis) et vos thèmes  
Paramètres avancés / Paramètres simples (setAdv) : mode simple par défaut (couleur principale, fond de la page, police du texte, police des titres, taille du texte, densité, activer les animations, vitesse des animations) ; mode avancé : toutes les catégories ci-dessous
